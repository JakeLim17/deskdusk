## 4. 화면 조작 (브라우저, 예시 값)

- 설정 열기·닫기(버튼, 닫기, Esc), 패널은 한 번에 하나만 열림
- 풍경 5종 전환과 저장
- 날씨 4종: 최대 속도에서 해당 입자만 나오고, 속도 0에서 모두 사라짐. 「계절 따라」는 11월에 눈
- 한도 0·30·60·80·100%의 시간대 낱말
- 카드 7개 각각 끄기, 전부 끄기, 다시 켜기
- 서비스 선택: 고른 서비스만 남고 합계·프로젝트·예측·머리글·풍경에 반영
- 카드 끌기: 이동, 화면 밖으로 못 나감, 폭 유지, 살짝 누른 것은 이동 아님, 「카드 위치 처음으로」
- 다시 열었을 때 풍경·날씨·숨긴 카드·서비스·카드 위치 유지
- 저장 값이 깨져 있어도 기본값으로 정상 표시
- 프로젝트 이름·요금제 이름에 태그 문자를 넣어도 실행되지 않음(글자로만 표시)

## 7. 하지 않았거나 할 수 없었던 것

- **실제 앱 창을 눈으로 확인하지 않았다.** 화면 조작 시험은 같은 화면 코드를 브라우저에서 돌린 것이다. 앱 창에서의 끌기, 설정 저장, 메뉴바 메뉴(「대시보드 열기」「종료」), 창 닫기 후 다시 열기는 사람이 확인해야 한다.
- 「Claude 한도 갱신 시도」 버튼은 다섯 번 중 한 번만 성공했고 원인을 찾지 못해 공개 준비 때 뺐다(9절).
- 자정을 넘길 때의 동작, 며칠 동안 켜 둔 상태.
- 다른 Mac, Intel Mac, 윈도우. 서명·공증이 없어 다른 Mac에서는 처음 열 때 경고가 뜬다.
- Gemini(미지원).
- 스크린 리더, 키보드만으로 카드 옮기기, 글자 확대.
- 정적 검사(clippy)는 설치돼 있지 않아 돌리지 않았다.
- 보안 교차 리뷰. Codex가 한도에 걸려 12월 10일까지 쓸 수 없다.
- 콘텐츠 보안 정책(CSP)은 꺼져 있다. 앱은 외부 내용을 불러오지 않고 표시 문자열은 모두 이스케이프하지만, 켜면 화면 모양이 깨질 수 있어 눈으로 확인할 수 있을 때 적용하는 것이 안전하다.
