바탕화면에 위젯을 띄웠어요다른 창 위에 작게 떠 있어요. 바탕화면에 깔아 두려면 위젯을 오른쪽 클릭해 「항상 위에 두기」를 끄거나, 메뉴바 메뉴의 「위젯을 다른 창 위에 띄우기」를 끄세요. 모양과 내용도 오른쪽 클릭으로 바꿔요.
Claude 한도를 정확하게 볼까요?켜면 이 컴퓨터의 Claude Code 로그인 정보로 Anthropic 서버에 한도를 물어요. 켤 때 키체인 접근을 물어볼 수 있어요. 끄면 로컬 기록만 읽어요.
컴퓨터를 켤 때 같이 켤까요?로그인할 때 창 없이 위젯과 메뉴바 요약만 올라와요.
이 창은 닫아도 돼요. 메뉴바의 DeskDusk 아이콘에서 다시 열 수 있고, 모두 「설정」에서 나중에 바꿀 수 있어요.
연결 상태로그인하지 않아요
DeskDusk는 기본 설정에서 Claude나 OpenAI에 접속하지 않아요. Claude Code와 Codex가 쓸 때마다 이 컴퓨터에 남기는 기록 파일을 읽을 뿐이에요.
켜면 이 컴퓨터에 저장된 Claude Code 로그인 정보로 Anthropic 서버에 한도를 10분마다 물어요. 켤 때 키체인 접근을 물어볼 수 있어요. 로그인 정보는 요청에만 쓰고 저장하지 않아요. 터미널 Claude Code에 로그인된 계정의 값이 나와요. 기본은 꺼짐이에요.
값의 출처이 컴퓨터의 기록만 읽어요
기본 설정에서는 로그인 정보를 읽지 않고 인터넷으로 보내는 것도 없어요. 한도 값은 각 도구를 마지막으로 쓴 시점의 값이라, 그 뒤로 안 썼다면 실제와 다를 수 있어요.
Claude 한도는 터미널에서 Claude Code를 쓸 때 새 값으로 바뀌어요.
